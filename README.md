# SABIZU-LP

商品「SABIZU（サビズ）キレート酵素」のランディングページ。
Meta（Facebook・Instagram）広告や公式LINEからの**流入専用**として作っている。
コーポレートサイトの1ページではないので、グローバルナビや他ページへのリンクは置かない。

掲載している事実情報（文言・価格・研究紹介・注意書き）は、wolf-g.jp の商品紹介ページ
https://wolf-g.jp/sabizu と同一。見出し・並び・畳み方だけがLP向けに変えてある。

## 構成

ビルド工程はない。静的ファイルをそのまま配信する（Cloudflare Pages / Workers、
Netlify、S3 など、どこでも `index.html` を配ればよい）。

```
index.html          LP本体（1ページ完結）
assets/styles.css   スタイル。配色・書体は wolf-g.jp と同じ値
images/             提供元支給の宣材（wolf-hp の public/images からコピー）
```

ローカルで確認するには適当な静的サーバを立てる。

```
python3 -m http.server 8000
```

## 公開前に必ず設定すること

1. **`og:image` を絶対URLにする** — `index.html` の `<meta property="og:image">` が
   相対パスのままだと、SNS・LINEでの共有時に画像が出ないことがある。
   公開ドメインが決まったら `https://<公開ドメイン>/images/og-sabizu.jpg` に書き換える。
   構造化データ（JSON-LD）の `image` も同様。
2. **広告ピクセルを入れる** — `<head>` にMetaピクセルのコメント枠を置いてある。
   ピクセルIDが決まったらコメントを外して `<PIXEL_ID>` を差し替える。
   購入の計測は遷移先である Stripe の決済完了ページ側で行うか、Stripeボタンの
   クリックを InitiateCheckout として送る。同意取得が必要な地域に配信する場合は、
   同意後に発火させること。
3. **`canonical` の向き先を確認する** — 本LPは wolf-g.jp/sabizu と同じ内容のため、
   両方を無指定のまま公開すると重複コンテンツになる。現在は広告流入専用の想定で
   **wolf-g.jp/sabizu を canonical に指定してある**。
   このLP自体を検索結果に出したくなった場合は、LPの公開URLに書き換える。

## 内容を変更するときの注意

wolf-g.jp（`wolf-ookami/wolf-hp`）の商品ページと**同じ内容を2箇所で持っている**。
価格・研究紹介・注意書きを直すときは、必ず両方を直すこと。
wolf-hp 側の情報源は `lib/content.ts` の `sabizu` / `sabizuPricing`。

掲載の決まりも wolf-hp と同じで、外すと法令上の問題になるものが含まれる。

- **効果・効能を書かない。** 本商品は食品のため、薬機法・景品表示法の観点から、
  キャッチコピー・特徴・成分値は提供元支給の宣材にある事実情報のみを載せる。
- **エビデンスの注意書きを外さない。** 研究紹介は成分「フルボ酸」一般に関する
  報告の紹介であり、本商品の効果の標榜ではない。セクション冒頭の注意書きと
  末尾の disclaimer は必ず表示する。各項目は出典（論文名・発表年・掲載誌の巻号
  ページ・著者）とセットで書き、書く前に論文の実在と書誌事項を確認すること。
- **ページ末尾の食品としての注意書きを外さない。**
- **販売メーターの数字は実数のみ。** 架空の販売数・支援額の表示は景品表示法
  （優良誤認・有利誤認）のリスクがある。実績が動いたら販売数・達成率・
  「◯年◯月◯日時点」をあわせて更新する。
- **価格・決済リンクの情報源は、提供元支給の「クラファンリターン価格表」。**
  クラウドファンディング期間が終了したらリターンの掲載を見直し、定価販売に戻す。
- **数字・日本語に Playfair Display を使わない。** 英字専用の飾り書体のため、
  数字は線が細く読みづらく、日本語は明朝にフォールバックする。数字は
  `.stat-num`、日本語は既定のゴシック。Playfair はロゴと英字ラベル専用。
- **会社の住所・電話番号は掲載しない**（wolf-g.jp 全体の方針）。
  問い合わせ窓口はメール（info@wolf-g.jp）のみ。

## LPとしての作りの決まり

広告からの流入を購入まで運ぶためのページなので、コーポレートサイト的な要素は足さない。

- **グローバルナビ（ページ内メニュー）を付けない。** 目次があると読み飛ばし先が増え、
  縦に読ませる流れが切れる。ページ内の導線は購入（`#buy`）だけに集約する。
- **本文に離脱先リンクを置かない。** コーポレートサイト・他事業ページ・商品紹介ページへの
  リンクは出さない。フッターに残すのは、表示義務のある特定商取引法に基づく表記と
  プライバシーポリシー、販売者名と問い合わせ先だけ。
- **1カラムを崩さない。** 読み幅は680px固定（`.wrap`）。画面が広くてもカードを横に
  並べない。写真も同じ幅に収める。
- **CTAを切らさない。** ファーストビュー・本文中・末尾にボタンを置き、画面下の固定バー
  （`.sticky-cta`）は全画面幅で出す。行き先はすべて `#buy`。
- **Stripeのリンクを `target="_blank"` にしない。** 広告のアプリ内ブラウザでは新しいタブが
  開かず、決済に進めないことがある。同一タブで遷移させる。
- **販売数・達成率のメーターは置かない。** 実績が0のあいだ「0本・達成率0%」を出すと、
  広告の着地ページとして逆効果になる。実績を出す場合は実数のみ（景品表示法）。
- **長い読みものはアコーディオン（`<details>`）に畳む。** ただしJSでの出し分けにはせず、
  HTMLには全文を残す。研究紹介の冒頭の注意書きと末尾の disclaimer は畳まず常時表示する。
