# SABIZU LP 設計方針

このLPを作り直すときの判断基準。文言・価格・研究紹介の**中身**のルールは README を、
ここでは**構成と見せ方**の意図を書く。

前提として、本商品は食品である。薬機法・景品表示法の観点から、
効果・効能を書かない／実績のない数字を作らない、が全項目に優先する。
LPの型（不安を煽る → 悩みを解決すると約束する → 実績で押す）は使えない、という制約から出発している。

---

## 1. ターゲット・想定読者

**主ターゲット**：30〜50代の女性。美容にお金と時間をかけていて、スキンケア（外側）は
すでに習慣化している層。Meta広告（Instagram / Facebook）からの流入を想定。

- 温度感：**低い**。商品を探していたのではなく、フィードの中で偶然見た人が大半。
  ブランド名を知らない状態で着地する。
- 価格感度：1本10,000円を出せる層。ドラッグストアのサプリではなく、
  デパコス・エステ・パーソナルジムと同じ財布から出る買い物として比較される。
- 障害：**フルボ酸を知らない**。「聞いたことのない成分の、1万円の飲みもの」を
  どう信じるかがこのLPの最大の課題。

**副ターゲット**：サロン・法人・卸（100本セットの受け皿）。主ターゲットの導線を
邪魔しないよう、価格表の最後とメール窓口だけに置く。

## 2. 訴求の軸（何を・いくらで・どうなるか）

| | 内容 |
|---|---|
| 何を | 国産の海洋性腐植土から抽出したフルボ酸エキス＋4種のミネラルを含む、500mLのインナーケアドリンク |
| いくらで | 定価13,000円 → クラウドファンディング先行販売で1本10,000円〜（まとめ買いで最大 定価比 約42%オフ） |
| どうなるか | **効果は言えない。**「外側のケアはしている人が、内側のケアを始める」という**習慣の提案**に置き換える |

3つ目が普通のLPと違うところ。「〜が改善する」と言えないぶん、
**「何をする商品か」を誤解の余地なく言い切る**ことに振っている。
ファーストビューの一文定義（「SABIZUとは、…インナーケアドリンクである。」）が軸。

## 3. ファーストビューのキャッチと構成順

構成順（縦1カラム）：

1. 告知バー（先行販売受付｜定価13,000円 → 1本10,000円〜）
2. ブランド名＋MADE IN JAPAN
3. **宣材ビジュアル**（スマホ＝縦／PC＝横で出し分け）
4. タグライン → キャッチ（H1）
5. 4つの要点タグ（フルボ酸／4種のミネラル／保存料・着色料不使用／日本製）
6. **価格枠**（定価に取り消し線 → 特別価格 → 定価比オフ → お届け予定）
7. CTA

キャッチは「キレイな人は、“内側”のケアも忘れない。」（提供元支給の宣材のコピー）。
効果を約束せず、**読者の自己像**に寄せる形なので、食品の制約と相性がよい。

宣材ビジュアルには文字が焼き込まれているため、**縦位置と横位置で別画像を使う**
（`<picture>` の `media` で出し分け）。横長画像をスマホで出すと焼き込み文字が潰れる。

## 4. ベネフィット表現／実績・数字の使い方

**使う数字は、実在が確認できるものだけ。**

| 使う | 使わない |
|---|---|
| 成分量（鉄26.7mg／カルシウム26.6mg／マグネシウム7.2mg／亜鉛5.75mg・100mlあたり） | 販売数・支援額・達成率（実績0のため） |
| 内容量 500mL | 満足度◯%・リピート率 |
| 価格・1本あたり単価・定価比の割引率 | 「◯日で実感」などの体感の数字 |
| 出典つきで掲載している研究報告の件数（8報） | 体験談・お客様の声（実績がない） |
| お届け時期（10月末〜11月初旬） | ランキング・受賞（事実がない） |

ベネフィットは動詞で書かない（「〜が整う」「〜をサポートする」は書かない）。
**事実の羅列＋読者が意味づけできる並び**にする。POINT 01〜05 は
すべて「配合しています」「含有しています」「使用していません」で終える。

研究紹介は**信頼の材料であって効能の根拠ではない**。
「ヒトを対象とした試験はまだ限られています」と自分から書くことが、
このカテゴリでは逆に信頼になる。注意書きを削らないのは法令上の要請であると同時に、
訴求上の判断でもある。

## 5. 価格提示の位置と見せ方

**3か所**に出す。それ以上は出さない（価格の情報源を散らかさない）。

1. **ファーストビューの価格枠** — 定価に取り消し線 → 特別価格を最大級の文字 → 定価比オフ → お届け予定
2. **価格セクション（#buy）** — 同じ対比を再掲したうえで、6セットを縦に並べる
3. **画面下の固定バー** — 「1本10,000円〜」と行き先だけ

見せ方の決まり：

- **二重価格表示になるため、割引の基準（定価13,000円）を必ず併記する。**
  バッジは「約23%オフ」ではなく「**定価比** 約23%オフ」と書く。
- 1本 → 2本 → 3本 → 6本 → 10本 → 100本の**昇順**。
  1本あたり単価が下がっていくことが縦に読める並びにする。
- 「おすすめ」「人気No.1」は付けない。販売実績がない以上、根拠のない推奨になる。
  代わりに「約3ヶ月分」「サロン・法人・卸のお客様向け」と**事実の補足**を置く。

## 6. CTAの種類と設置箇所

| 種類 | 行き先 | 役割 |
|---|---|---|
| 主 | Stripeの決済ページ（各セット） | 購入。価格セクションにのみ置く |
| 副 | `#buy`（ページ内） | 価格セクションへ送る。ページ全体で繰り返す |
| 第三 | `mailto:info@wolf-g.jp` | 卸・見積もり・開始通知の相談。価格セクション末尾とフッターのみ |

設置箇所：ファーストビュー／特徴の後／世界観の帯／研究紹介の後／価格／Q&Aの後／末尾／固定バー。
**副CTAを繰り返し、主CTAは価格セクションに集約する**。決済リンクを本文に散らすと、
どのセットを買っているのか分からないまま決済ページに飛ばすことになる。

Stripeのリンクは `target="_blank"` にしない。広告のアプリ内ブラウザで新規タブが開かず、
決済に進めないことがある。

## 7. FAQ・反論処理

Q&Aは体裁ではなく**反論処理**として置く。想定される断り文句に、1問ずつ対応させている。

| 読者の心の声 | 対応する設問 |
|---|---|
| フルボ酸って何？怪しい | フルボ酸とは？ |
| 効くの？ | 効果はありますか？（→ **食品であり効果は保証しない**と正面から答える） |
| 高い | 価格はいくら？／まとめ買いの単価 |
| 定期縛りでは？ | 定期購入ですか？ |
| 味が不安 | どんな味？ |
| いつ届くの？ | いつ届く？ |
| 支払いは？ | 支払い方法は？ |
| 誰が売ってる？ | 販売元は？ |
| 返品できる？ | キャンセル・返品は？（→ 特定商取引法に基づく表記へ） |

「効果はありますか？」に**ごまかさずに答える**のがこのLPの肝。
食品であること、研究は成分一般の紹介であることを自分から書く。

## 8. デザイン面（色数・文字量・図解比率）

- **色数は3＋1**：黒 `#0a0a0a` / 生成り `#f7f6f2` / 白、アクセントに金 `#8a6d17`（黒地では `#d4af37`）。
  CTAだけ黄 `#ffc400`。**金をボタンに使わない**（押せる要素が識別できなくなる）。
- **1カラム・読み幅680px固定**。画面が広くてもカードを横に並べない。
- **文字量**：1セクション＝1メッセージ。本文14〜16px、注記12px。
  出典・総説など読み飛ばせるものは `<details>` に畳む（HTMLには全文を残す）。
- **図解比率**：テキストだけの画面が3つ続かないよう、
  宣材写真・数字ストリップ・ミネラル表・STEP図をセクションの区切りに挟む。
  現状は約6画面ごとにビジュアルが入る。
- **地色のリズム**：白 → 生成り → 黒帯 を繰り返し、1カラムでもセクションの
  変わり目が分かるようにする。黒帯はブランドステートメントとCTAに割り当てる。
