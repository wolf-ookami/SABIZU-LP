# 競合LP比較と、他商材への転用案

調査日：2026年9月1日。公開情報（検索結果・商品ページのタイトルと概要）にもとづく。
価格は税込・調査時点のもので、変動する。**採用する前に必ず現物のページで裏を取ること。**
`shop.slow-village.jp` と `wolf-g.jp` は調査環境から直接開けなかったため、検索結果の記載を引いている。

## 1. まず確認が必要なこと（最優先）

**旧名称「セルクレンズ」が、Amazon・楽天で第三者ショップから流通している。**

- Amazon：「国産海洋性フルボ酸原液100％飲料 セルクレンズ 500ml 天然 植物性マルチミネラル ケイ素」
  （同一ASINの別タイトルに「**【雑誌掲載】**」の表記あり）
- 楽天：同名商品を「スピード発送 Reapri（リアプリ）」が販売。商品名に
  「**【楽天ランキング1位入賞】**」の表記あり

README に「旧名称は Cell Cleanse（セルクレンズ）」とあり、商品説明（国産海洋性フルボ酸・500mL・
ケイ素／亜鉛／鉄）も一致するため、**同一または前身の商品である可能性が高い**（未確認）。

LPへの影響は2方向ある。

| | 内容 | 打ち手 |
|---|---|---|
| リスク | 「SABIZU」「フルボ酸 500ml」で比較検索されたとき、**同じ説明の商品が別の値段で買える**状態になっている。10,000円という先行販売価格の説得力が崩れる | 販売チャネルと価格の整合を取る。旧名称品の販売主体・在庫・価格を確認し、必要ならLPに「SABIZUは◯◯としてリニューアルした商品です」の一文を置く |
| 資産 | 「楽天ランキング1位入賞」「雑誌掲載」は、**同一商品なら使える実績**。現在のLPには実績表記が1つもない | 事実と表示根拠（順位の対象カテゴリ・集計期間、掲載誌名と号）を揃えられるなら、権威性の材料として使う。**裏付け資料なしに書くと景表法違反**になるので、資料が出るまでは書かない |

これは競合分析というより、**自社商品の流通実態の確認**にあたる。LPの改修より先に片付けたい。

## 2. 競合マップ

「フルボ酸」で検索した人が同じ画面で見る商品は、価格帯が3層に分かれている。

| 層 | 例 | 価格の目安 | SABIZUとの関係 |
|---|---|---|---|
| A. フルボ酸**原液**・ミネラル飲料 | オーガニックフルボ酸原液「ミネフル70」720mL（スローヴィレッジ）：**定期購入 15,120円** | 100mLあたり 約2,100円 | **直接競合。価格帯がほぼ同じ** |
| | セルクレンズ 500mL（Amazon・楽天） | 未確認 | 上記のとおり要確認 |
| | ミネラルジュエル ネオ 500mL（日本フルボ酸総合研究所） | 未確認 | 直接競合 |
| B. フルボ酸**ウォーター** | 奥長良川名水 フルボ酸ウォーター 500mL×24本 | 1本あたり数百円 | 別カテゴリだが**検索結果には並ぶ**。「フルボ酸なのに桁が違う」と見える |
| C. 一般の美容・インナーケアドリンク | コラーゲン・プラセンタ系のドリンク | 1本100〜500円／箱で数千円 | 「内側からの美容習慣」で競合。**本数単価では絶対に勝てない** |

**価格ポジション**（100mLあたりに換算）

| | 100mLあたり | 備考 |
|---|---|---|
| SABIZU 定価 13,000円 | **2,600円** | A層の定期価格より高い |
| SABIZU クラファン 1本 10,000円 | **2,000円** | ミネフル70の定期（約2,100円）とほぼ横並び |
| SABIZU 6本まとめ 8,500円 | 1,700円 | A層で最も安い部類 |
| SABIZU 100本 7,500円 | 1,500円 | 卸価格帯 |
| ミネフル70（定期） | 約2,100円 | 720mLボトル |

**読み取れること**：定価13,000円のままだとA層の中で割高に見える。
クラファン価格10,000円で**ようやく横並び**、まとめ買いで優位に立つ、という位置。
いまのLPが「まとめ買いほど1本あたりが下がる」を縦に読ませる構成になっているのは、
この価格構造とは合っている。逆に、**1本単品を主役に据えると価格で負ける**。

## 3. カテゴリ定番のLP構成 vs SABIZU

健康食品LPの定石は、複数の制作会社の記事でほぼ一致している
（初回限定価格の訴求／定期購入のメリット明示／解約の簡単さ／体験談／権威性／成分エビデンス）。
それに対して現在のSABIZU LPがどうなっているか。

| 定番の型 | 一般的な健康食品LP | SABIZU LP | 判断 |
|---|---|---|---|
| **初回限定価格** | 「初回500円」など極端な割引で1回目を取り、2回目以降で回収 | なし。クラファン特別価格（定価比23〜42%オフ）のみ | **取れない**。クラファンの先行販売で、継続前提の設計になっていない |
| **定期購入** | 本体。LPの目的は定期の申込 | なし。都度購入 | **取っていない**。ただし後述のとおり**強みに変えられる** |
| **解約の簡単さ** | 「回数縛りなし」「いつでも解約」を大書 | Q&Aに「継続課金のご登録ではありません」 | 弱い。**もっと前に出せる** |
| **体験談・お客様の声** | 顔写真つきで3〜5件 | なし | **取れない**（実績ゼロ。捏造は景表法違反） |
| **満足度◯%・モニター調査** | 「93%が実感」等 | なし | **取れない**（調査をしていない） |
| **権威性（雑誌掲載・ランキング）** | バッジで並べる | なし | **取れる可能性あり**（1章の確認待ち） |
| **成分エビデンス** | 独自成分の図解、研究の引用 | 論文8報を出典つきで掲載 | **カテゴリ最上位の水準**。ここが唯一の差別化点 |
| **医師・専門家の監修コメント** | 顔写真つき | なし | 未着手。取りに行く価値はある |
| **効果の断定** | 薬機法上、断定は不可（「シミが消える」等はNG、「きれいを維持しよう」等は可） | 断定なし。Q&Aで「効果は保証しない」と明言 | 法令順守としては**過剰なほど安全側** |
| **限定性・緊急性** | 「残り◯個」「本日まで」 | なし（期間の記載のみ） | クラファンの期間が決まれば**期限は書ける** |

**総評**：このLPは、カテゴリの定番武器のうち「価格の仕掛け」「社会的証明」を**構造的に使えない**。
そのぶん**エビデンスの厚みと誠実さ**に全振りしている状態で、方向としては正しい。
ただし、使えるのに使っていないカードが3枚ある（次章）。

## 4. 使えるのに使っていないカード（優先度順）

### ① 「定期縛りなし」を、価格の隣に置く

このカテゴリの購入者が最も警戒しているのは**定期縛り**で、競合LPが「回数縛りなし」を
大書しているのはそのため。SABIZUは**構造的に縛りがない**のに、その事実がQ&Aの
4問目に埋まっている。価格枠の直下に一行置くだけで、カテゴリ最大の不安を先回りで消せる。

> 例：「定期購入ではありません。今回かぎりのお申し込みです。」

### ② 100mLあたり・1回あたりの価格に換算する

10,000円は**単体では高く見える**が、100mLあたり2,000円は競合の定期価格と同じ。
比較の土俵を「1本の値段」から「量あたりの値段」に移すと、価格の見え方が変わる。
**1日あたりに換算するには1回の飲用量が要る**ので、支給資料に飲用量の記載があるかを確認したい。
記載がなければ100mLあたりまでにとどめる。

### ③ 期限を書く

クラウドファンディングの開始日・終了日が決まったら、
「◯月◯日まで」を価格枠と固定バーに入れる。期間限定は**事実として書ける唯一の緊急性**。
「残り◯個」は在庫の裏付けが必要なので使わない。

### ④（要確認）実績バッジ

1章の「楽天ランキング1位入賞」「雑誌掲載」が同一商品のもので、
順位の対象カテゴリ・集計期間・掲載誌名まで資料が揃うなら、権威性として置ける。
**資料が出ない場合は書かない。**

## 5. 自社の他商材への転用案

このLPは「**効果を言えない商材を、言わずに売る**」ための型として作ってある。
同じ制約を持つ商材（食品・化粧品・健康関連）にはそのまま流用できる。

### 転用できる「型」

1. **一文定義を最初に置く** — 「◯◯とは、△△が取り扱う、□□を使用した〜である。」
   効能を語れないぶん、**何であるかを一文で言い切る**。AIの検索結果に引用されやすい形でもある。
2. **事実で終わる箇条書き（POINT 01〜05）** — 「配合しています」「使用していません」で終える。
   動詞で効果を書かない。
3. **エビデンスを出典つきで、畳んで載せる** — 論文名・掲載誌・巻号ページ・著者をセットにし、
   `<details>` で畳む。冒頭の注意書きと末尾の disclaimer は畳まない。
4. **反論処理としてのQ&A** — 「効果はありますか？」に正面から「保証しません」と答える。
   この誠実さ自体が、規制カテゴリでは差別化になる。
5. **実在する数字だけの数字ストリップ** — 成分量・容量・件数・価格。実績のない数字は置かない。
6. **1カラム680px・色数3＋1・地色のリズム（白→生成り→黒帯）**

### 実装としての転用手順

現状は `index.html` に内容と型が混ざっている。2商材目を作るときに分ける。

```
assets/styles.css        ← そのまま流用できる（商材固有の色だけ :root で差し替え）
docs/lp-strategy.md      ← 判断基準。商材ごとに「ターゲット」「訴求の軸」だけ書き換える
index.html               ← 2商材目を作るときに、この構造をコピーして中身を入れ替える
```

3商材目を作る段になったら、共通部分（head・固定CTA・reveal スクリプト・フッター）を
テンプレート化する。それまでは**コピーで足りる**。ビルド工程を持たない方針なので、
テンプレートエンジンを入れるのは商材が3つ以上になってからでよい。

### 商材タイプ別の出し分け

| 商材の性質 | この型のどこを変えるか |
|---|---|
| 効能を言える（規制なし） | エビデンス章を「導入事例・実績」に差し替え、Q&Aの「効果はありますか？」を落とす |
| 単価が安い（〜3,000円） | まとめ買いの階段をやめ、1商品1ボタンにする。価格の見せ場は1か所で足りる |
| 継続課金がある | 「定期縛りなし」の代わりに解約条件を明示する章を、価格の直後に置く |
| BtoB・法人向け | 主CTAを購入から**問い合わせ／資料請求**に変える。価格は「要見積」でも成立する |
